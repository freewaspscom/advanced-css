# advanced-css

This website is for FireTracker, a program I hope to create sometime in the future for creating music. 
It features:
- Flexbox used for the nav and footer
- Grid used for the features
- Two breakpoints for mobile
- Nav stacks on mobile and is a full bar on desktop
- Button hover and features hover
- The features all slide in on load
- Dark mode uses variables
- Includes a toggle button
- The theme stays upon reloading
- One h1
- Can be navigated with a keyboard
- Color contrast readable
